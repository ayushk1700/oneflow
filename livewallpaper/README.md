# Live wallpapers

Place your licensed MP4 or WebM files directly in this folder. Run `npm run wallpapers`, reload the extension, then choose **Options → Settings → Scenery → From livewallpaper** (or use the visual customizer).

The catalog is currently empty. No placeholder video is shipped. Videos load only when selected, loop silently, pause in hidden tabs, and respect reduced motion. Broken or removed videos leave the starter still visible. Prefer short, optimized loops; media in this folder is included in extension packages.

The catalog stores filenames rather than copying videos into browser storage. Exported settings/scenes reference those files: keep the same files with the extension when moving it to another computer. Browser-uploaded videos remain supported separately and keep their existing backup behavior.
