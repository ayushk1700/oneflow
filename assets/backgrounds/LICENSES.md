# Original landscapes

The six bundled backgrounds are original ONEFLOW SVG illustrations. Stage 1's collection (Stillwater, Quiet coast, Lavender dusk, Sage meadow, Blue hour, Desert hush) is generated by `scripts/refresh-wallpapers.js`, including optimized WebP images and thumbnails. Stable IDs keep existing scene selections working. There are no external photographs, stock-image dependencies, API calls, or attribution requirements. Source SVGs are included for editing.

User-uploaded images remain the user's own material and are stored only locally.
`scripts/assets.js` can also render the saved SVG sources. Development uses the existing Sharp runtime; no image-processing dependency is loaded by the extension.
